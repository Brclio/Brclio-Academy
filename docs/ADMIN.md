# 管理员与内容维护

## 1. 创建管理员

首次安装不含默认账号与密码。在项目目录使用与线上一致的存储配置，执行：

```bash
read -s ADMIN_PASSWORD
export ADMIN_PASSWORD
npm run admin -- --email owner@example.com --name Brclio
unset ADMIN_PASSWORD
```

该操作创建已验证的管理员账号，密码至少 10 位、最多 128 位。它不发送注册邮件、不自动开通 VIP、不覆盖已有账号密码。已有学员账号通过邮箱验证后，可以提升为管理员：

```bash
npm run admin -- --email owner@example.com --promote
```

管理员操作会记录到审计记录。后台不会显示密码哈希、验证码或原始会话令牌。

## 2. 管理学员与 VIP

1. 学员完成邮箱验证注册后，登录管理员后台，在用户列表找到他的邮箱。
2. 设置一个未来的 VIP 截止时间并保存。
3. 学员刷新页面后可以进入全部已发布课程与 VIP 文章。
4. 续期时设置新的截止时间；立即停用时点击“撤销 VIP”，再确认撤销。

VIP 截止时间存储为带时区的 ISO 时间。界面中的本地时间会转换后保存；跨时区管理时核对显示的时区与日期。到达截止时刻即视为失效，无需定时任务。后台表单要求新期限晚于当前时间；如需立即取消，使用“撤销 VIP”。

管理员权限与 VIP 独立。需要体验学习页时，为自己的账号也设置有效 VIP。当前没有支付或自动售卖入口，VIP 由管理员开通。

| 身份 | 课程目录 | 课文 / 视频 ID / 资源 | 公开文章 | VIP 文章 | 自己的收藏与历史 | 后台 |
| --- | --- | --- | --- | --- | --- | --- |
| 游客 | 可看 | 不可看 | 可看 | 不可看 | 不可看 | 不可用 |
| 普通已登录用户 | 可看 | 不可看 | 可看 | 不可看 | 可看；可以收藏课程 | 不可用 |
| 有效 VIP | 可看 | 可看 | 可看 | 可看 | 可看；可以保存学习进度与笔记 | 不可用 |
| 管理员，无 VIP | 可看 | 学习接口不可看；内容管理接口可编辑 | 可看 | 学习接口不可看；后台可编辑 | 可看 | 可用 |

账户页展示已注册昵称、邮箱、注册时间和会员状态；当前不支持在线修改昵称或邮箱。修改密码通过邮箱验证码找回流程完成。

VIP 过期后保留已有进度、收藏与个人笔记，便于续期后继续。平台不承诺撤回用户之前已经获得、下载或另行转发的内容。

## 3. 管理课程

课程层级为 **课程 → 章节 → 课时 → 一段或多段视频**。章节与课时按照数组顺序展示。后台保存会校验字段，格式错误时不会写入数据库。

### 用后台表单创建一门课

1. 打开“管理后台 → 课程管理”，点击“新建课程”。
2. 填写课程名称、介绍、分类、难度和学习成果。没有测量过总时长时写“按自己的节奏”。
3. 填写首章标题，展开“编辑课时内容”。选择视频或图文类型，填写课时标题、正文与配套任务；视频课可直接粘贴完整 YouTube 链接。
4. 用“添加课时”“添加章节”补齐系列结构，上下箭头调整顺序。一个课时中的多段视频也可以分别上移或下移。
5. 点击“保存课程”先存为草稿。核对无误后勾选“发布课程”再保存，学员目录才会展示。

以下字段表与 JSON 用来解释数据结构，日常操作直接使用后台表单即可。后台会自动生成稳定 ID。

### 课程字段

| 字段 | 用途 |
| --- | --- |
| `id` | 稳定唯一标识，例如 `my-first-course`；小写字母、数字、连字符、下划线 |
| `title` / `subtitle` | 标题与一句话介绍 |
| `description` | 课程详细说明，不要在公开说明中填私密视频链接 |
| `category` / `level` | 分类与适用水平 |
| `duration` | 时长文字；没有真实时长时写“按自己的节奏” |
| `color` | `blue`、`yellow`、`green`、`pink` |
| `cover` | 课程封面预设：`film`、`python`、`web`、`workflow`；不是任意图片 URL |
| `featured` | 是否作为推荐课程 |
| `published` | 是否公开目录并允许进入学习 |
| `demo` | 是否显示为示例课程 |
| `outcomes` | 可验证的学习成果列表 |
| `chapters` | 有序章节数组，每章包含有序 `lessons` |
| `updatedAt` | ISO 时间；保存时服务端会更新 |

### 可参考的课程对象

下面是一个可填写内容的模板。示例视频 ID 来自已有 AI 课程，正式使用时替换成自己的 ID。

```json
{
  "id": "my-first-course",
  "title": "我的第一门系列课程",
  "subtitle": "用一个具体作品串起学习过程。",
  "description": "写清适合谁、前置准备和最终交付物。",
  "category": "项目实践",
  "level": "入门",
  "duration": "按自己的节奏",
  "color": "blue",
  "cover": "film",
  "featured": false,
  "published": false,
  "demo": true,
  "outcomes": ["完成一个可以展示的作品"],
  "chapters": [
    {
      "id": "chapter-01",
      "title": "开始之前",
      "lessons": [
        {
          "id": "lesson-01",
          "title": "课程介绍",
          "duration": "视频课",
          "kind": "video",
          "content": "## 本节目标\n\n写下你的学习目标。\n\n## 练习\n\n完成一份项目草图。",
          "videos": [{ "id": "u13DKz6cnbo", "title": "课程介绍" }],
          "resources": []
        }
      ]
    }
  ],
  "updatedAt": "2026-09-10T00:00:00.000Z"
}
```

完整对象中的必填字段都要保留。发布前先保存为 `published=false`，检查内容结构、练习、视频与链接，再发布。发布或下架后，公共目录和受保护接口会按新状态返回结果。

### 课时和多视频

YouTube 地址 `https://www.youtube.com/watch?v=u13DKz6cnbo` 的视频 ID 是 `u13DKz6cnbo`。`videos` 数组每项是 `{ "id": "11位视频ID", "title": "片段标题" }`，多个片段按数组顺序排列。YouTube 短链接也提取同一 11 位 ID；不要把整个网址写进 ID 字段。

图文课设置 `kind="article"`、`videos=[]`，在 `content` 写 Markdown。学习任务、代码、列表、标题、链接、表格和图片都可用。图片使用 `![说明](https://example.com/image.png)` 或 `public` 目录资源路径（如 `/brand/avatar.png`）；仅支持 HTTPS 与本站路径，没有内置图片上传服务。正文按 Markdown 渲染，不执行 HTML 或脚本。

`resources` 为可选学习资源列表，格式为 `{ "title": "练习文件", "url": "https://example.com/resource" }`。当前资源使用 HTTPS/HTTP 外链，平台没有内置文件上传或下载鉴权服务；如果资源本身需要保密，请使用有独立访问控制的资源服务。

### 调整章节顺序时保留 ID

章节与课时的显示顺序由数组位置决定，移动条目即可。不要通过修改 ID 来实现重命名或排序：学习记录和笔记关联的是 `courseId + lessonId`。仅修改标题不会丢失关联，改 ID 相当于新课时。移除课时会使它的历史记录不再出现在学员可见列表中。

如果需要暂时停止整门课的访问，设置 `published=false`。不要直接删除整个数据文件。

## 4. 管理文章与专栏

在“专栏”标签点击“新建专栏”，填写名称、简介和主题色后保存；再到“文章”标签点击“新建文章”，选择“所属专栏”，设置“专栏内排序”和“阅读权限”。勾选发布选项后保存，才能在学员侧看到。

专栏是有序文章的归属，不与课程章节混用。数据中先创建专栏，再给文章设置对应 `columnId`。

专栏字段：

```json
{
  "id": "my-column",
  "title": "我的新专栏",
  "description": "持续记录一个主题。",
  "color": "green",
  "published": false
}
```

文章字段：

```json
{
  "id": "my-first-article",
  "title": "第一篇文章",
  "summary": "这里是公开展示的摘要。",
  "content": "## 从一个问题开始\n\n这里写正文。",
  "category": "学习方法",
  "access": "vip",
  "columnId": "my-column",
  "order": 1,
  "published": false,
  "readMinutes": 3,
  "updatedAt": "2026-09-10T00:00:00.000Z"
}
```

- `access="public"` 的正文游客也能读；`access="vip"` 的正文需要有效 VIP。
- 标题、摘要、分类和阅读时间是公开元数据，摘要中不要放受保护全文。
- `columnId=null` 表示独立文章。专栏内使用 `order` 控制阅读顺序。
- `readMinutes` 是整数阅读时间估计；正文变化后同步调整，不当作视频时长。
- 专栏下架会让归属它的文章一并从公共目录和阅读接口隐藏；独立文章不受影响。

## 5. 示例数据说明

首次初始化包括 4 门示例课程、15 个章节、35 个课时、19 段用户提供视频、2 个专栏和 6 篇文章。所有课程的 `demo=true`。Python、个人网站和 AI 工作流是完整图文示例，没有假视频链接。

示例定义位于 `src/lib/seed.ts`，只在服务器初次创建数据库时使用。之后请通过后台维护已有数据；修改 seed 不会自动覆盖数据库。

正式私有课程的视频 ID 与完整正文应通过后台录入，落到私有数据存储。代码仓库中的示例链接对能够查看源码的人可见，因此不要把正式保密内容继续硬编码进 seed 并推到公开仓库。

## 6. 日常维护

定期导出加密备份，具体命令见 [部署教程](DEPLOYMENT.md)。大规模修改前保留备份；先在独立测试环境导入恢复一次，检查内容与账号数量。

后台审计记录展示 VIP 变更和内容保存的操作人、时间与目标。它用于回查运维操作，不等于独立的不可篡改审计服务。不要直接在 GitHub 页面编辑加密文件；也不要把数据库解密后的内容提交到代码仓库。
